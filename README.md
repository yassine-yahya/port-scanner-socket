# A fast and efficient port scanner built using Python's socket and threading modules. 🚀

## ⚡ Features
- ✅ Scans multiple ports quickly using multi-threading
- ✅ Detects open and closed ports
- ✅ Uses custom timeouts for better performance
- ✅ Colorful terminal output for easy readability 🎨

## 🛠 Installation
Clone the repo:

git clone https://github.com/yassine-yahya/port-scanner-socket.git
cd port-scanner-socket
Install dependencies (optional for color support):

### pip install colorama
🚀 Usage
Run the script and enter the target IP:

### python port_scanner.py
📌 Example Output

### Scanning target 192.168.1.1...
[+] Port 80 is OPEN
[-] Port 443 is CLOSED
Total ports scanned: 625
